# Budget Tracker — Apple Shortcuts (Log Expense)

A lightweight, ultra-fast expense logger shortcut built for Apple Shortcuts, written in [Cherri](https://cherrilang.org/).

---

## 1. Context: Original `Track_Expenses` vs New `Log Expense`

### The Original Shortcut (`asset/ref/Track Expenses.txt`, 162 actions)
The earlier version had good initial ideas (Share Sheet input parsing, currency reading, device stamping), but suffered from major performance bottlenecks:
- **Whole-history rewrites**: Read and parsed the entire `transactions.json` dictionary on every run and re-serialized the whole file on every save.
- **Recursive retries**: Retried invalid input by calling itself via `Run Shortcut` (`is.workflow.actions.runworkflow`), keeping old execution frames in memory.
- **Setup overhead**: Ran folder creation routines on every launch.
- **Payload bloat**: Included ~128 KB of base64 vCard icons and reporting logic, causing noticeable launch lag on iOS devices.

### The New `Log Expense` (`src/log-expense.cherri`)
- **Append-only storage**: Transactions are written to month-specific log files (`Expenses Tracker/data/yyyy-MM.txt`). Previous history is never opened or parsed during logging.
- **In-memory validation loop**: Retries invalid amounts using a `for retry in 50` loop inside the same run without invoking `Run Shortcut`.
- **Silent first-run bootstrap**: Checks if `Expenses Tracker/config/budget.json` exists; only creates directories and seeds defaults if missing (zero extra taps).
- **Dynamic category filter**: Parses `budget.json` and filters for categories where `type == "spend"` (currently `Essentials` and `Discretionary`).
- **Lean execution**: Zero vCards, zero base64 blobs, zero extraneous reports. Total execution per log: ~25 actions executed at runtime.

## 3. Data Architecture (iCloud Drive)

```
iCloud Drive/Expenses Tracker/
├── config/
│   ├── budget.json     # Groups, categories, limits, and types
│   └── prefs.json      # Currency symbol, note toggle, schemaVersion
├── data/
│   └── 2026-10.txt     # One append-only pipe-delimited file per month (yyyy-MM.txt)
└── Receipts/           # Reserved for future receipt attachments
```

### Pipe-Delimited Log Format (7 Fields)
Each transaction is appended as a single line to `data/<yyyy-MM>.txt`:
```
id|date|categoryId|amount|source|device|note
```

#### Fields:
1. `id`: Timestamp formatted `yyMMddHHmmss` (e.g. `261011160530`).
2. `date`: Timestamp formatted `yyyy-MM-dd HH:mm` (e.g. `2026-10-11 16:05`).
3. `categoryId`: Stable lowercase ID from `budget.json` (e.g. `essentials`, `discretionary`).
4. `amount`: Plain numeric value without currency symbols or commas (e.g. `150`).
5. `source`: `manual` (hook for future automation).
6. `device`: Value from `Get Device Details > Device Name` (e.g. `iPhone`).
7. `note`: Sanitized free-text note (any `|` character is converted to `/`). Empty if note toggle is off.

#### Example lines:
```
261003081500|2026-10-03 08:15|essentials|150|manual|iPhone|jeep fare
261003124000|2026-10-03 12:40|discretionary|85|manual|iPhone|
```

## 5. Build & Compilation

### Prerequisites
Install the Cherri compiler (macOS):
```bash
brew tap electrikmilk/cherri
brew install cherri
```

### Compile
Compile `src/log-expense.cherri` to `build/log-expense.shortcut`:
```bash
./build.sh log-expense
```
Or directly using the compiler:
```bash
cherri src/log-expense.cherri -o=build/log-expense.shortcut
```

### Install onto Device
- **AirDrop**: Right-click `build/log-expense.shortcut` on macOS and AirDrop it to your iPhone.
- **iCloud Drive**: Move `build/log-expense.shortcut` to any folder in iCloud Drive and tap it in the Files app on iOS.
- **macOS Shortcuts**: Double-click `build/log-expense.shortcut` to open and import directly into macOS Shortcuts.

## 6. On-Device Test Checklist (iPhone)

Execute the following manual test scenarios to verify all edge cases:

- [ ] **1. First-Run Bootstrap (No Config)**
  - Ensure the `Expenses Tracker` folder does not exist in iCloud Drive (or rename it).
  - Run `Log Expense`.
  - **Verify**: The shortcut runs smoothly with no errors and opens directly to the category picker (`Essentials`, `Discretionary`).
  - **Verify**: Files `Expenses Tracker/config/budget.json` and `prefs.json` were created in iCloud Drive.

- [ ] **2. Normal Log**
  - Run `Log Expense`.
  - Select `Essentials`, enter `150`.
  - **Verify**: Modal alert displays `✓ ₱150 · Essentials`.
  - **Verify**: Open `Files > iCloud Drive > Expenses Tracker > data > <yyyy-MM>.txt`. A single 7-field line is present with amount `150` and category `essentials`.

- [ ] **3. Consecutive Appends & Newline Verification (Critical)**
  - Run `Log Expense` a second time immediately.
  - Select `Discretionary`, enter `85`.
  - **Verify**: Open `data/<yyyy-MM>.txt`. There are exactly **2 lines**.
  - **Verify**: Lines are distinct and **not merged** on one line, and there are **no blank lines** in between.

- [ ] **4. Numeric Input from Share Sheet / Siri**
  - Highlight the number `250` in Safari or Notes.
  - Tap Share → `Log Expense`.
  - **Verify**: Amount prompt is skipped; category picker appears immediately; transaction records with `250`.

- [ ] **5. Non-Numeric Input Fallback from Share Sheet**
  - Highlight plain text `lunch` (non-numeric).
  - Tap Share → `Log Expense`.
  - **Verify**: Input is silently ignored; category picker opens, followed by the normal "Enter amount:" prompt.

- [ ] **6. Amount Validation & In-Run Retry Loop**
  - Run `Log Expense`. Select `Essentials`.
  - Enter `0`: Verify alert `"Amount must be greater than 0."`, followed by a re-prompt.
  - Enter `-25`: Verify alert `"Amount must be greater than 0."`, followed by a re-prompt.
  - Enter `1500000`: Verify alert `"Amount cannot exceed 1,000,000."`, followed by a re-prompt.
  - Enter `75`: Verify transaction records successfully without restarting the shortcut.

- [ ] **7. Note Prompt & Pipe Sanitization**
  - In `Files > iCloud Drive > Expenses Tracker > config > prefs.json`, edit `"note": true`.
  - Run `Log Expense`. Select `Discretionary`, enter `90`.
  - When prompted for note, enter `coffee|cake|snack`.
  - **Verify**: Line in `data/<yyyy-MM>.txt` ends with `manual|<Device>|coffee/cake/snack` (pipes replaced with slashes).

- [ ] **8. New Month Rollover**
  - When a transaction is logged in a new month (e.g. November), verify a new file `2026-11.txt` is automatically created in `Expenses Tracker/data/`.

## 7. Assumptions & Technical Details

1. **Newline Behavior**: Cherri compiles `appendToFile` to Apple Shortcuts' native `is.workflow.actions.file.append`. Shortcuts natively handles newline delimiters when appending text (auto-prepending a newline if the file does not terminate with one). Therefore, `@line` does not append a trailing `\n` to avoid double-spacing. This is explicitly verified in Test #3.
2. **Dynamic Name-to-ID Mapping**: Because Shortcuts' `chooseFromList` returns the selected text item (not an arbitrary object), the shortcut builds an in-memory dictionary `@nameToId` mapping `name -> id` (e.g. `Essentials -> essentials`), guaranteeing that only clean names are shown in the UI while stable lowercase IDs are saved in the data file.
3. **Loop Termination**: Because Apple Shortcuts does not support a `break` keyword, entering a valid amount and successfully appending calls `stop()` to cleanly terminate the 50-iteration retry loop.
